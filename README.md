# CampusMind AI

A RAG-powered multilingual chatbot for college information and student services.

## Project Goal

CampusMind AI provides students and parents with reliable information about the college using official college documents.

## Planned Features

- RAG-based chatbot
- English and Telugu support
- Official document-based answers
- Student login and profile
- Chat history
- Admin document management
- Source citations
- Human query escalation
- Answer feedback
- Basic analytics dashboard
